# MarkEdit for Windows

A **Markdown** editor built on the MarkEdit editor core.

## Features

- CodeMirror 6 editing core
- GitHub flavored themes
- Find and replace
- Table of contents

### Code sample

```js
const editor = new EditorView({ parent: document.body });
```

> Quotes, lists and tables work too.

| Column | Item |
| ------ | ---- |
| a      | 1    |
| b      | 2    |
